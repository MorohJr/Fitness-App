# אפליקציית כושר אישית (PWA)

מקור האמת: [`SPEC.md`](SPEC.md). כל שינוי מתעדכן שם קודם.
כתובת: https://morohjr.github.io/Fitness-App/

## פקודות

```bash
npm install     # פעם אחת, מתקין את החבילות
npm test        # כל הבדיקות האוטומטיות
npm run dev     # הרצה מקומית לפיתוח
npm run build   # בנייה לתיקיית dist
```

## פרסום

כל `push` לענף `main` מריץ את הבדיקות, בונה ומפרסם ל-GitHub Pages (`.github/workflows/deploy.yml`).
ב-GitHub Desktop: **Push origin**. אחרי 2–3 דקות האפליקציה בטלפון מציגה "גרסה חדשה זמינה" → **רענן**.

## מבנה

לפי SPEC 3.2: `src/domain` (לוגיקה וכללים), `src/data` (מסד נתונים, גיבוי, בדיקות שיוצרות הצעות), `src/ui` (מסכים), `tests` (בדיקות).

## בדיקות קבלה שדורשות אייפון (פרק 8)

בדיקות אוטומטיות מכסות את כל החישובים והכללים. את אלה אפשר לבדוק רק במכשיר:

| שלב | בדיקה |
|---|---|
| 1 | התקנה במסך הבית ופתיחה במצב טיסה |
| 1 | ייצוא בטלפון ← ייבוא במחשב ← אותם נתונים. ביטול ייבוא מחזיר את המצב הקודם |
| 4 | סריקת ברקוד של מוצר שקיים ב-Open Food Facts ממלאת ערכים |
| 5 | נעילת מסך באמצע מנוחה ← חזרה ← הטיימר מדויק, והבהוב + צליל בסוף |
| 5 | המסך לא נכבה בזמן אימון |
| 6 | צילום תמונות במדידה, השוואה בין תאריכים, "שמור לאפליקציית התמונות" |
| 8 | עבודה מלאה של כמה ימים: היום, תזונה, אימון, גוף, דשבורד, מצב כהה ובהיר |
| 9 | טעינת נתוני הדגמה באייפון (כולל תמונות) ← "החזר את הנתונים שלי" ← הנתונים המקוריים חזרו |
